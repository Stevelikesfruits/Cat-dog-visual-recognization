# 优化目标函数

## 1. 定义

“优化目标函数”包含了 Loss和正则化惩罚项.
在学术界和严谨的代码工程中，这三个词有严格的层级划分：

### (1).  损失函数 (Loss Function)

- **符号：** $L(\hat{y}_i, y_i)$
- **定义：** 计算**单个样本**的预测值 $\hat{y}_i$ 与真实值 $y_i$ 之间的误差。
- **例如：** 均方误差 (MSE) 的单个样本 Loss 是 $(\hat{y}_i - y_i)^2$。

### (2).  代价函数 (Cost Function)

- **符号：** $J(W)$
- **定义：** 计算整个训练集（或一个 Batch）所有样本 Loss 的平均值。
- **公式：** $J(W) = \frac{1}{N} \sum_{i=1}^{N} L(\hat{y}_i, y_i)$

### (3).  目标函数 (Objective Function)

- **符号：** $Obj(W)$
- **定义：** 任何你希望在优化算法中**被最小化（或最大化）的那个最终的数学表达式**。
- **公式：** $Obj(W) = \text{Cost Function} + \text{Regularization Term}$  即：
  $$
  Obj(W) = \frac{1}{N} \sum_{i=1}^{N} L(\hat{y}_i, y_i) + \lambda R(W)
  $$
  

## 2. 前置知识: L1和L2

在数学泛函分析中，L1 和 L2 只是一个庞大得多的家族——**Lp 范数 (Lp Norm)** ——的两个特殊成员。

### (1). Lp范数

Lp 范数的通用公式：
$$
L_p = \left( \sum_{i=1}^{n} \vert{}w_i\vert{}^p \right)^{\frac{1}{p}}

### (3). 为什么不用L3,L4?

- 在正则化中:

  1. **“高不成低不就”的尴尬形状：**

     我们需要 L1，是因为它的“尖角”能带来特征剔除（变 0）；我们需要 L2，是因为它的“圆滑”能在数学上极易求导（平方的导数是线性函数）。

     而 L3、L4 的形状既没有尖角（无法稀疏化），求导又极其复杂（比如 4 次方求导是 3 次方，容易引起数值爆炸），完全是个累赘。

  2. **计算成本过高：**

       在几千万参数的大模型里，算 L2 只需要算一下平方和。如果要算 L3、L4，需要算高次幂，这会让显卡的计算负荷大幅增加，却带不来任何比 L2 更好的收益。\



## 3. **Loss的选择** 与 **范数的出现场景**

### (1). **Loss的选择** 

一般情况下, 是按照任务的不同来选择Loss函数

| 任务          | 例子               | 用的损失                 |
| ------------- | ------------------ | ------------------------ |
| 图像分类      | 猫狗识别、手写数字 | **交叉熵**(CrossEntropy) |
| 回归          | 房价、温度         | L1(MAE)或 L2(MSE)        |
| 图像生成/修复 | 去噪、超分、GAN    | L1(常用),L2(易糊)        |

### (2). 范数在损失和正则化中都有使用

L1和L2的**一体两面**, 下表显示了他们的使用:

| 身份             | 作用在什么上   | 回答的问题 | 在 torch 里的位置       |
| ---------------- | -------------- | ---------- | ----------------------- |
| **L1/L2 损失**   | 输出 vs 真实值 | 结果差多少 | `l1_loss` / `MSELoss`   |
| **L1/L2 正则化** | 网络权重 W     | 参数大不大 | 优化器的 `weight_decay` |
