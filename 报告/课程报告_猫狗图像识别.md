# 项目简要介绍

本项目基于 PyTorch 构建了一套完整的猫狗图像二分类识别系统，从数据、模型、预测三个环节走通了深度学习应用的全流程。团队从零手写卷积神经网络（3 个 Conv→BN→ReLU 卷积块 + 全局平均池化 + Dropout + 全连接分类头，参数量约 29.6 万），并借助 kagglehub 自动下载整理 Kaggle Dogs vs Cats 数据集（猫 5011 张、狗 5017 张）。通过数据增强、Adam 优化器、最优模型自动保存等工程手段，最终模型在验证集上取得 84.3% 的整体识别准确率（猫 94.5%、狗 74.1%），并配套了批量预测、置信度输出、训练曲线可视化等可直接使用的功能。项目最大的亮点是"理论笔记 + 手写代码 + 可复现实验"三位一体：每一处设计（BN、Dropout、L2 正则化、MSRA 初始化）都能在学习摘要中找到对应推导，每一行代码都有实测数据支撑。

## 1. 项目背景与目标

猫狗图像识别是深度学习与卷积神经网络（CNN）领域最经典的入门任务之一：数据集公开易得、任务直观、评价指标清晰，非常适合把理论学习转化为实际动手能力。

本小组的目标不只是"跑出一个能识别的程序"，而是希望通过一个完整的项目闭环，**把此前学习的 CNN 理论真正落地**：

- 从零搭建网络结构，而不是直接套用现成模型，以加深对卷积、池化、BN、Dropout 等每个组件的理解；
- 完整经历"数据获取 → 数据整理 → 模型设计 → 训练调参 → 评估预测"的工程流程；
- 用数据说话，量化每一步选择（网络结构、训练轮数、数据增强）对结果的影响。

## 2. 总体方案与技术路线

整体流程如下：

```
┌────────────┐   ┌────────────┐   ┌────────────┐   ┌────────────┐
│ 1. 理论学习 │→│ 2. 数据准备 │→│ 3. 模型训练 │→│ 4. 评估预测 │
│  CNN/BN/优化│  │ Kaggle下载 │  │ 自建CNN     │  │ 准确率评估  │

└────────────┘   └────────────┘   └────────────┘   └────────────┘
```

对应实现为三个独立脚本，各自职责单一、可单独运行：

| 脚本 | 职责 | 关键产出 |
|---|---|---|
| `download_data.py` | 自动下载数据集并整理 | `data/train`、`data/val` 的 cat/dog 目录 |

| `predict.py` | 加载模型进行推理 | 单张/批量识别结果与置信度 |

技术栈：PyTorch 2.13 + torchvision + CUDA（RTX 4060 Laptop GPU），开发环境为 Anaconda 独立环境 `pytorch_env`。

## 4. 数据准备与数据工程

### 4.1 数据来源与自动下载

采用 Kaggle 经典的 Dogs vs Cats 数据集，编写 `download_data.py` 通过 `kagglehub` 库**自动下载并解压**（无需注册账号），免去手动下载、找路径的麻烦。脚本具备幂等保护：检测到数据已存在时直接跳过，避免重复下载。

### 4.2 数据整理

下载的原始数据目录结构杂乱（文件名、嵌套子目录不统一），脚本通过文件名前缀（`cat.xxx.jpg` 风格）与目录名双重规则智能归类，按 8:2 划分训练集/验证集并复制为标准 ImageFolder 结构：

```
data/
├── train/  cat 4008张  +  dog 4013张
└── val/    cat 1003张  +  dog 1004张
```

### 4.3 数据增强（抑制过拟合）

训练时对图片做随机裁剪缩放（RandomResizedCrop）、随机水平翻转（RandomHorizontalFlip）、颜色抖动（ColorJitter），相当于把 8000 张图"扩充"成各种变体，让模型学到"位置、方向、亮度无关"的本质特征。这正对应理论中学习的"数据增强作为正则化手段"的思想。

## 5. 模型设计与实现

### 5.1 网络结构（自建，非预训练）

模型完全从零搭建，参数量约 29.6 万，输入 128×128 RGB 图像：

| 层 | 结构 | 输出尺寸 | 设计意图 |
|---|---|---|---|
| 卷积块 1 | Conv(3→32)+BN+ReLU ×2, MaxPool | 64×64×32 | 提取底层边缘、纹理特征 |
| 卷积块 2 | Conv(32→64)+BN+ReLU ×2, MaxPool | 32×32×64 | 组合局部特征 |
| 卷积块 3 | Conv(64→128)+BN+ReLU ×2, MaxPool | 16×16×128 | 高层语义特征 |
| 全局池化 | AdaptiveAvgPool(1) | 128 维向量 | 特征汇总，摆脱输入尺寸限制 |
| 分类头 | Dropout(0.5)→FC(128→64)→ReLU→FC(64→2) | 2 维 logits | 输出猫/狗得分 |

每一处设计都与理论学习一一对应：**BN** 加速收敛并起到正则作用；**MaxPool** 下采样扩大感受野；**Dropout** 随机丢弃神经元抑制过拟合；卷积层默认采用 **MSRA（Kaiming）初始化**。

### 5.2 训练配置

| 超参数 | 取值 | 说明 |
|---|---|---|
| 优化器 | Adam，lr=1e-3 | SGD 的改进版，自适应学习率 |
| 正则化 | weight_decay=1e-4 | L2 正则化，抑制过拟合 |
| 损失函数 | CrossEntropyLoss | 分类任务标准损失 |
| 批大小 | 64 | 显存与收敛速度的平衡 |
| 训练轮数 | 12（可扩展） | 每轮约 40 秒 |
| 学习率调度 | ReduceLROnPlateau | 验证损失不降时自动减半 |

**工程亮点：** 采用"验证准确率创新高才保存"策略（而非保存最后一轮），保证产出的模型始终是训练全程的最佳版本。

## 6. 训练过程与结果分析

### 6.1 训练日志（节选）

```
[轮次  1] 训练 loss=0.6452 acc=0.6235 | 验证 loss=0.7027 acc=0.6054 | 耗时 40s
[轮次  6] 训练 loss=0.5004 acc=0.7634 | 验证 loss=0.4496 acc=0.7907 | 耗时 41s
[轮次  9] 训练 loss=0.4375 acc=0.8024 | 验证 loss=0.4071 acc=0.8256 | 耗时 49s
[轮次 12] 训练 loss=0.3714 acc=0.8349 | 验证 loss=0.3657 acc=0.8430 | 耗时 40s
```

训练 loss 从 0.65 稳步降至 0.37，准确率从 62% 升至 84%，全程 12 轮约 8.5 分钟。训练曲线（loss / accuracy 双图）自动保存为 `outputs/training_curves.png`。

### 6.2 最终结果

在 2007 张**从未参与训练**的验证集上评估：

| 指标 | 结果 |
|---|---|
| 整体准确率 | **84.3%**（1692/2007） |
| 猫识别率 | **94.5%**（948/1003） |
| 狗识别率 | **74.1%**（744/1004） |

### 6.3 结果分析与问题发现

1. **"偏猫"现象**：模型对狗的识别明显弱于猫。分析原因有二：一是狗品种间长相差异极大（吉娃娃、哈士奇、柯基），类内差异大于猫，小网络更难学全；二是训练保存策略以总准确率为准，天然偏向易学的猫类。这是后续优化的重点方向。
2. **验证曲线震荡**：验证损失在第 10 轮出现明显回弹（acc 跌至 60%）后又在第 12 轮创新高，说明小模型 + 固定学习率存在收敛震荡。这也印证了"以历史最佳模型为准"策略的必要性。
3. **优化方向**：增加训练轮数（20+）、加深网络或引入迁移学习（ResNet18 微调可达约 99%），均可进一步提升。

## 7. 预测系统与使用效果

`predict.py` 加载训练好的模型，对任意图片输出"猫/狗 + 置信度"，支持单张与文件夹批量两种模式：

```
python predict.py 我的猫.jpg          →  我的猫.jpg → 猫 (置信度 92.3%)
python predict.py data/val/dog        →  批量统计: 猫 260 张, 狗 744 张
```

置信度（softmax 概率）作为模型"自我确信程度"的输出，可当作免费的异常检测信号：置信度接近 50% 时说明图片存在歧义（特殊角度、遮挡、卡通画），提醒用户谨慎采信。
